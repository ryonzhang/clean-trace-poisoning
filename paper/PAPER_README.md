# Compiling main.tex

`main.tex` targets the Springer LNCS class (`\documentclass[runningheads]{llncs}`).

**Recommended: compile on Overleaf**

1. Go to https://www.overleaf.com/gallery/tagged/springer and open the official
   **"Springer LNCS Proceedings"** template — this provides the licensed `llncs.cls`.
2. Replace the placeholder `main.tex` with the one from this directory (no other changes needed).
3. Click **Compile** (pdflatex x2).

`llncs.cls` is not bundled here as it is Springer's copyrighted file.
